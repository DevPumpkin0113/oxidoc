원인: Monaco find.addExtraSpaceOnTop 기본 동작으로 62px view zone 생성. 범위: 해당 옵션 비활성화, 찾기/치환 오버레이와 기존 기능 유지. 완료 조건: 창 열기·치환 확장 시 상단 추가 공간 미생성. 검증: 실제 브라우저 view zone·본문 위치 비교, 타입/린트/빌드.

구현·검증: find.addExtraSpaceOnTop=false 적용. 실제 브라우저에서 기존 62px view zone 재현 후 수정된 찾기/바꾸기 모두 추가 높이 0·첫 본문 줄 위치 동일 확인. 검색 입력·치환 확장·Esc 유지 확인. 타입·린트·프로덕션 빌드 및 포맷 적용 통과.
