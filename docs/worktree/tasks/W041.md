범위: 활성 프로젝트에서 탐색기 폴더 열기 숨김, 문서 없는 본문의 상태별 안내/새 문서 진입, WORKSPACE 대신 실제 루트 폴더명 및 경로 툴팁 표시. 프로젝트 없는 초기 상태의 폴더 열기 유지. 검증: 프로젝트 없음/있음·문서 없음·표시 이름과 실제 폴더명 차이·구분자/긴 이름 처리.

구현·검증: 프로젝트 유무로 탐색기 폴더 열기 분기. 활성 프로젝트의 빈 본문은 문서 선택 안내·새 문서 진입(브라우저 샘플은 문서 검색). 실제 루트 폴더명과 경로 툴팁·긴 이름 말줄임. 프로젝트 없음/있음·표시명과 실제 폴더명 분리 회귀 포함 프런트엔드 62개·타입·린트·빌드·포맷 통과. 별도 새 샘플 창의 변경 없는 기본 문서로 빈 화면 안내/검색 동작 확인. 기존 미저장 탭 버리기 검사는 자동 승인 검토 거부로 미실행·기존 내용 보존. 서브에이전트 검토 완료·추가 문제 없음.
