목적·범위: 명령 팔레트 및 프로젝트 검색·열기 명령

완료 조건: 명령 팔레트 진입과 프로젝트 검색·선택·열기

검증 방법: 키보드 기반 팔레트 실행부터 프로젝트 열기까지 확인

구현·검증: Ctrl P/Ctrl Shift P 팔레트·프로젝트 이름/경로 검색·프로젝트 열기 명령. 키보드 화살표/Enter 실행·Escape 닫기 테스트.

통합 검증: npm run check 통과, 프런트엔드 38개·Rust 9개 테스트 통과. 서브에이전트 1명 검토 및 발견 항목 수정·재검토 완료. Windows 네이티브 선택창의 수동 UI 조작은 미실행, 관련 명령은 컴파일·상태/파일 테스트로 검증.
