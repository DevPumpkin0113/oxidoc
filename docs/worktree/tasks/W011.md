목적·범위: 프로젝트 상대 경로 이미지 및 문서 링크 처리

완료 조건: 현재 문서 위치 기준 상대 경로 해석과 이미지 표시·문서 이동

검증 방법: 중첩 폴더 문서의 이미지·링크 및 누락 대상 처리 확인

구현·검증: 중첩 문서 상대 경로 해석·로컬 이미지 데이터 URL·문서 및 앵커 이동. 외부 경로·누락 오류 처리와 대소문자 별칭 탭 중복 방지 테스트.

통합 검증: npm run check 통과, 프런트엔드 38개·Rust 9개 테스트 통과. 서브에이전트 1명 검토 및 발견 항목 수정·재검토 완료. Windows 네이티브 선택창의 수동 UI 조작은 미실행, 관련 명령은 컴파일·상태/파일 테스트로 검증.
