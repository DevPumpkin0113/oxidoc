목적·범위: 문서 열기·저장·다른 이름으로 저장

완료 조건: 파일 읽기·수정 내용 저장·새 경로 저장

검증 방법: 저장 파일 재열기 후 내용 일치 및 저장 실패 처리 확인

구현·검증: Ctrl S 및 Ctrl Shift S 연결. 원본 보존 새 경로 저장, 기존 대상 충돌·미저장 대상 보호, 취소·실패·저장 중 추가 편집 보존 검증.

통합 검증: npm run check 통과, 프런트엔드 38개·Rust 9개 테스트 통과. 서브에이전트 1명 검토 및 발견 항목 수정·재검토 완료. Windows 네이티브 선택창의 수동 UI 조작은 미실행, 관련 명령은 컴파일·상태/파일 테스트로 검증.
