원인: 팔레트 내부 keydown에만 연결된 Esc, 입력창 외부 포커스에서 닫기 불가 및 명시적 닫기 버튼 부재. 범위: 닫기 버튼·전역 capture Esc·배경 클릭 닫기·입력/닫기 버튼 포커스 순환·IME 입력 보호. 완료 조건: 포커스 위치와 무관한 Esc 닫기 및 닫기 버튼 Enter가 명령을 실행하지 않는 동작. 검증: 회귀 테스트·타입/린트/빌드·브라우저 확인.

구현·검증: 닫기 버튼·포커스 밖 Esc·Tab/Enter·배경 클릭·IME 보호 및 listener 정리 회귀 테스트 통과. 실제 브라우저에서 입력 blur 후 Esc, 닫기 버튼 클릭, Tab/Enter 닫기 확인.

검증 결과: 프런트엔드 54개 테스트·타입·린트·프로덕션 빌드·포맷 통과, 서브에이전트 1명 검토 완료·추가 문제 없음. Rust 변경 없음.
