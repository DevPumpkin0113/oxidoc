목적·범위: 프로젝트 이름 수정 및 목록에서 제거

완료 조건: 표시 이름 수정과 등록 정보 제거, 실제 폴더 및 파일 유지

검증 방법: 이름 수정 영속화 및 목록 제거 후 실제 파일 보존 확인

구현·검증: 표시 이름·등록 정보 변경 영속화와 목록 제거. 목록 제거에서 파일 삭제 API 미호출 및 현재 작업 공간 초기화 테스트.

통합 검증: npm run check 통과, 프런트엔드 38개·Rust 9개 테스트 통과. 서브에이전트 1명 검토 및 발견 항목 수정·재검토 완료. Windows 네이티브 선택창의 수동 UI 조작은 미실행, 관련 명령은 컴파일·상태/파일 테스트로 검증.
