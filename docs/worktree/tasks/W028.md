목적·범위: 이동한 프로젝트의 폴더 경로 재지정

완료 조건: 기존 등록 정보 유지와 프로젝트 폴더 경로 갱신

검증 방법: 폴더 이동 후 재연결·재실행 및 프로젝트 열기 확인

구현·검증: 등록 metadata 유지 재연결·중복 경로 방지·세션 키 및 마지막 프로젝트 경로 이동·저장 실패 rollback. 재연결 상태 복원 테스트 및 리뷰에서 발견한 이전 경로 존재 의존 제거.

통합 검증: npm run check 통과, 프런트엔드 38개·Rust 9개 테스트 통과. 서브에이전트 1명 검토 및 발견 항목 수정·재검토 완료. Windows 네이티브 선택창의 수동 UI 조작은 미실행, 관련 명령은 컴파일·상태/파일 테스트로 검증.
