범위: 같은 프로젝트의 단일 파일을 폴더/루트로 드래그 이동, 대상 강조, 충돌·프로젝트 외부 경로 차단, 열린 문서 경로·미저장 버퍼 유지, 트리 및 세션 갱신. 폴더 자체 이동·OS 외부 파일 가져오기 제외. 완료 조건: UI 드롭 이벤트·상태·실제 파일 이동/충돌/경계 테스트 및 타입·린트·빌드 통과.
구현: 파일 버튼 draggable, 폴더/루트 summary 드롭 강조·성공 후 펼침. Windows HTML DND를 위한 dragDropEnabled:false, 전역 capture로 외부 Files 기본 열기 차단. MoveFileExW 덮어쓰기 플래그 미사용으로 동시 생성 충돌 차단. 열린 문서 미저장 버퍼·활성 경로 유지 및 세션 갱신.
검증: npm run check 통과(프런트엔드 69개·Rust 12개·버전 CLI 4개), 타입·린트·포맷·빌드 통과. Tauri debug --no-bundle 실행 파일 빌드 통과, 서브에이전트 검토 지적 보완·재검토 완료. 실제 데스크톱 마우스 드래그 미실행: 자동 UI 검증 CLI 부재/레지스트리 연결 실패. UI 드롭 이벤트 및 실제 파일 이동은 각각 자동 테스트 검증. 창 설정 반영에 앱 재실행 필요. 기존 Monaco 청크 크기 경고 유지.
