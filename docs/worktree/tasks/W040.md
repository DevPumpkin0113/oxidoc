목적·범위: 편집기/미리보기 높이 차이로 끝까지 스크롤 시 상대 화면의 하단이 남는 문제 수정. 완료 조건: 상단/하단 끝 위치 명시 연동, 중간 소스 줄 보간 유지, 늦은 콘텐츠 높이 변경 및 피드백 루프 보호. 검증: 긴 표·코드·줄바꿈 문서, 양방향 끝 스크롤·폰트 크기 차이·크기 변화 회귀 및 실제 브라우저 확인.

구현·검증: 소스 줄 위치와 별도로 start/end 정보 전달, 양방향 실제 scrollHeight/viewport 끝 위치 적용. 편집기 끝에서 지연 렌더링·이미지·글꼴 높이 변경 시 ResizeObserver로 미리보기 하단 유지. 직접 스크롤·개요/검색/앵커 이동 시 고정 해제. 수정 전 100행 표 문서의 미리보기 하단 잔여 418px 재현, 수정 후 0px 확인. 역방향 스크롤 및 편집기 10px/미리보기 32px·표 높이 증가 검증.

검증 결과: 프런트엔드 테스트 60개·타입·린트·빌드·포맷 통과, 서브에이전트 검토에서 발견한 navigation 고정 해제 보완 및 재검토 완료. Rust 변경 없음.
