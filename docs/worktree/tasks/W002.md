목적·범위: VS Code 스타일 작업 공간 UI 및 커스텀 창 제어 구성

완료 조건: 사이드바 상단 가로 액티비티·탐색기·편집 영역·상태 표시줄 배치, 문서 탭과 창 제어 통합, 창 크기 변경 시 편집 영역 가용성 유지

최종 디자인: 공통 배경 위 독립된 사이드바·콘텐츠 패널(1px 외곽선·8px 곡률·6px 간격). 패널 위 34px 행에 문서 탭·창 제어 배치, 활성 탭은 본문과 연결. 비활성 탭 테두리 제거, 닫기 버튼은 활성·호버·포커스·변경 상태에 표시. 타이틀바 아이콘·제목·검색란 제외, 패널 전환 버튼은 상태 표시줄 왼쪽 배치

구현 결과: 다크 그린 테마, 탐색기·검색·프로젝트 패널, 샘플 문서 탭 및 변경 표시, Monaco 편집·Markdown 미리보기·분할 보기, Ctrl K 검색·Ctrl B 패널 전환. UI 아이콘은 Codicons SVG, 파일·폴더는 Material Icon Theme. Tauri 창 장식 제거·창 제어 권한 설정 및 라이선스 리소스 포함

검증 결과: 타입·린트·UI 테스트 4개·프런트엔드 빌드 통과, 최신 탭 디자인 브라우저 화면 확인. 앞선 검사에서 포맷·Clippy·Rust 테스트 실행 통과. 1280×820·640×480 패널 간격·외곽선·창 제어 노출·가로 넘침 없음 확인, 폴더 아이콘 상태 전환·패널 닫기/열기·문서 전환·검색 확인

제약: 실제 폴더 연결·파일 저장·프로젝트 영속화 미구현. Monaco 청크 크기 경고 존재. 별도 Rust 단위 테스트 0개. 네이티브 창 드래그·최소화·최대화·복원·닫기는 실제 사용자 확인 필요

현재 상태: 자체 검증 완료, UI 및 네이티브 창 제어 사용자 확인·승인 대기

상단 높이 정렬: 사이드바 아이콘 영역 축소 및 메인 탭 행과 34px 기준 공유, 패널 외곽선 1px 반영. 브라우저 실측 사이드바 구분선과 메인 패널 상단 모두 y=39px, 차이 0px 확인. 빌드 통과.

프로젝트 항목 축소: 큰 세로 카드를 높이 36px 한 줄 버튼으로 변경. 16px 아이콘·이름·열림 상태 점만 표시, 샘플 정보는 툴팁으로 제공. 타입 포함 빌드 통과, 브라우저 실측 확인.
