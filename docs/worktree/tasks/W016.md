목적·범위: 편집기·미리보기 스크롤 동기화

완료 조건: 편집기와 미리보기의 대응 문서 위치 연동

검증 방법: 이미지·표·코드 블록 포함 긴 문서의 양쪽 스크롤 연동 확인

구현·검증: 소스 줄 기반 블록 위치 보간 및 양방향 스크롤 동기화, 피드백 억제. 긴 문서 브라우저 양방향 위치 연동 확인, 탭 전환 시 억제 상태 초기화.

통합 검증: npm run check 통과, 프런트엔드 38개·Rust 9개 테스트 통과. 서브에이전트 1명 검토 및 발견 항목 수정·재검토 완료. Windows 네이티브 선택창의 수동 UI 조작은 미실행, 관련 명령은 컴파일·상태/파일 테스트로 검증.
