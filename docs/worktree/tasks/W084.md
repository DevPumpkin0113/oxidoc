목적: 문서 중심 탐색기 정리. 범위: 기본 보기 md/mmd/mermaid 파일과 해당 문서가 하위에 있는 폴더만 표시·전체 보기 모든 항목 표시·보기 설정 복원·빈 폴더 안내/펼침 제거·우클릭/붙여넣기/드롭 유지. 완료 조건: 중첩 빈 폴더 및 비문서 전용 폴더 기본 숨김, 전체 보기 빈 폴더 행만 표시, 생성/이동/새로고침 이후 상태 갱신·잘못된 비동기 결과 반영 방지. 검증: 네이티브 디렉터리 메타데이터·필터/설정·폴더 동작·파일 이동/생성 회귀.

검증: 기본 문서 확장자/재귀 폴더 필터·전체 보기·빈 폴더 비확장/안내 없음·관리/드롭 후 펼침·상위 mtime 불변인 깊은 숨김 자손 변경 재평가 회귀 통과. 네이티브 문서 유무·실제 빈 폴더·검사 범위 소진 시 잘못 숨기지 않는 동작 확인. 실제 Chrome에서 기본/전체 전환과 큰 글꼴 버튼 확인. 문서 모드의 폴더 메타데이터는 3초 주기로 로드된 각 가지 재확인, 디렉터리 조회당20,000항목/깊이64·확인불가폴더 유지.

공통 검증: 프런트엔드150개·Rust26개·버전/배포6개 테스트 및 타입·린트·빌드·포맷·Clippy 통과. 서브에이전트 재검토 추가 차단 문제 없음. 커밋/릴리즈 미진행.
