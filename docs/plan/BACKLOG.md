# 예정 작업

진행 순서와 상태는 `.agent/plan.md` 기준. 여기에는 남은 작업의 범위·완료 조건·검증 방법만 두고, 끝난 작업은 릴리즈 때 지운다(내용은 git 이력, 결과는 `CHANGELOG.md`).

## 기능

### 파일·폴더 다중 선택

- 목적: 탐색기 여러 항목의 일괄 관리
- 범위: Ctrl/Shift 선택·선택 표시·일괄 복사/잘라내기/붙여넣기·이동/휴지통 이동·다중 드래그·선택별 우클릭 메뉴
- 완료 조건: 부모/자식 중복 처리·이름 충돌·부분 실패 안내·열린 문서 버퍼 유지
- 검증: 선택/키보드 회귀 테스트·실제 파일 일괄 작업 및 실패 시나리오

### Markdown 편집 도구

- 목적: Markdown 구문 작성 편의 개선
- 범위: 굵게/기울임·제목·링크/이미지·코드 블록·체크리스트 삽입/전환·표 생성/정렬 도구
- 완료 조건: 선택 영역/커서 유지·실행 취소 단위·기존 단축키/찾기 입력 분리·언어/테마 대응
- 검증: 선택/다중 줄·구문 전환·표 셀 이스케이프·실행 취소 및 실제 편집기 동작

### front matter 처리

- 범위: 문서 맨 앞 YAML front matter(`---`로 감싼 블록)를 미리보기에서 본문 대신 접힌 속성 표로 표시, 개요·링크 검사·블록 분할에서 제외, 편집기 구문 강조
- 완료 조건: front matter가 구분선·제목으로 잘못 보이지 않고 본문 줄 번호·스크롤 동기화가 맞는다
- 검증: front matter 있음/없음/닫히지 않음·본문 중간 `---` 구분 테스트

### 자동 저장

- 범위: 설정에서 끄기·입력 멈춤 후 저장·포커스 이동 시 저장 선택, 외부 변경 충돌 시 자동 저장 중단과 안내
- 완료 조건: 켜면 수정한 문서가 지정 조건에 저장되고, 외부 변경·저장 실패 시 버퍼를 잃지 않는다
- 검증: 지연 저장·포커스 이동·충돌·실패 테스트

### 내보내기·인쇄

- 범위: 현재 문서를 미리보기와 같은 모양의 HTML·PDF로 내보내기와 인쇄, 로컬 이미지 포함, 테마(라이트 고정 선택)
- 완료 조건: 내보낸 파일이 앱 없이 같은 내용으로 보이고 보안 정책(허용 HTML)이 유지된다
- 검증: 이미지·코드 강조·Mermaid·한글 포함 문서 내보내기 확인

### 프로젝트 밖 파일 단독 열기

- 범위: OS에서 연 파일이 등록 프로젝트 밖이면 폴더 등록 없이 `External` 작업 공간에 폴더별로 모아 연다. 현재 프로젝트 탭과 한 창에 섞는 방식은 문서마다 소속 루트가 필요해 제외(2026-11-18 결정)
- 완료 조건: 연 파일을 편집·저장·외부 변경 감지·복구할 수 있고, 앱이 접근하는 경로는 등록 프로젝트와 OS가 넘긴 파일로 한정된다
- 검증: 작업 공간 시작·추가·등록 전환 테스트, 실제 실행 인자로 열기 확인

### 외부 파일 끌어다 놓기

- 범위: OS 탐색기의 이미지를 편집기에 놓으면 `assets`에 복사하고 링크 삽입, 파일·폴더를 탐색기에 놓으면 프로젝트로 복사
- 완료 조건: 이름 충돌·크기 제한·비허용 형식을 안내하고 등록 경로 밖으로 쓰지 않는다
- 검증: 단일·여러 파일·충돌·취소 테스트, 실제 드롭 확인

### 수식 표시

- 범위: `$…$`·`$$…$$` 수식을 미리보기에서 KaTeX로 렌더링
- 완료 조건: 잘못된 수식은 원문과 오류를 보이고 코드 블록 안 `$`는 건드리지 않는다

### 백링크

- 범위: 현재 문서를 가리키는 다른 문서 목록(개요 패널 또는 사이드바), 클릭 시 해당 위치로 이동
- 완료 조건: 파일 변경·이동 뒤 목록이 갱신된다

### 폴더 끌어서 이동

- 범위: 탐색기에서 폴더를 끌어 다른 폴더로 이동(자기 하위로 이동 금지), 링크 갱신 연동

### 뒤로·앞으로 이동

- 범위: 링크·검색 결과·개요 이동 기록을 따라 이전/다음 위치로(`Alt ←`/`Alt →`)
