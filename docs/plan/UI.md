# 화면과 기능

## 레이아웃

- 최상단 34px 행: 문서 탭과 창 제어 통합, 별도 타이틀바 없음. 탭 옆·사이드바 아이콘 사이 빈 영역은 창 드래그(더블클릭 최대화), 앱 아이콘·제목·검색란 제외.
- 사이드바: 상단 가로 액티비티(탐색기·검색·프로젝트, 밑줄로 선택 표시), 아이콘 영역 하단 경계를 탭 행과 같은 34px에 정렬. 타이틀 아래 첫 콘텐츠 상단 8px·좌우 12px, 세 패널 공통 CSS 변수.
- 본문: 문서 탭·경로·보기 전환·편집/분할/미리보기.
- 문서 도구막대: 찾기·바꾸기 | 실행 취소·다시 실행 | 개요·스크롤 동기화 | 다른 이름으로 저장·저장 | 보기 전환. 툴팁은 `기능 이름 (단축키)` 형식. 도구막대 폭 620px 이하에서는 실행 취소·다시 실행·개요·동기화·다른 이름 저장을 더 보기 메뉴로, 420px 이하에서는 저장 글자와 경로를 숨겨 한 줄 유지.
- 프로젝트 탭(데스크톱): 상태 표시줄 왼쪽(설정·사이드바 버튼 다음)에 연 프로젝트와 `External`을 탭으로 표시하고, 넘치면 가로 스크롤(휠). 브라우저 미리보기는 현재 프로젝트 이름만 표시. 탭마다 열린 문서·활성 문서·미저장 편집·탐색기 펼침·레이아웃을 메모리에 따로 유지해, 탭을 바꿔도 저장을 묻지 않는다(미저장 편집은 복구 임시본에도 남음). 미저장 문서가 있는 탭은 ● 표시. 클릭·`+`(폴더 선택)로 열기, 닫기 버튼·가운데 클릭으로 닫기(그 탭의 미저장 문서만 확인), 끌기(끄는 탭은 흐리게, 놓일 위치는 강조색 세로 막대로 표시)·`Alt Shift ←/→`로 순서 변경. 등록 프로젝트 탭 목록과 순서는 재실행 시 복원하고(External 제외), 다시 연 탭은 저장된 세션으로 시작. 프로젝트 목록에서 프로젝트를 고르면 그 탭으로 전환하거나 새 탭으로 연다.
- 상태 표시줄: 사이드바 열기/닫기·현재 프로젝트·현재 문서 저장 상태(저장됨·저장 안 됨·외부에서 변경됨·파일 없음)·글자 수(공백 포함, 줄 바꿈 제외)·단어 수·커서 위치·문서 형식·설정. 편집기에 선택 영역이 있으면 선택 영역 기준으로 셈.
- 사이드바 너비: 사이드바와 콘텐츠 패널 사이 6px 틈을 끌어 180~600px로 조절(마우스를 올리면 강조색 선, 최소 너비보다 60px 넘게 왼쪽으로 끌면 접히는 미리보기 후 놓을 때 사이드바 닫기(너비는 기억), 더블클릭은 기본 240px, 포커스 후 `←`/`→` 16px·`Home`/`End`). 끄는 동안은 화면만 바꾸고 놓을 때 저장하며, 모든 프로젝트 탭이 같은 너비를 쓰고 재실행 시 복원. 창이 좁으면 콘텐츠가 360px 이상 남도록 사이드바를 줄여 표시.
- 패널: 어두운 앱 배경 위 독립 사이드바·콘텐츠 패널, 1px 외곽선·8px 곡률·은은한 그림자. 패널 사이·상단·좌우 6px, 하단 4px. 맞닿는 이중 경계선 없음.
- 문서 탭: 활성 탭만 얇은 외곽선·8px 상단 곡률로 콘텐츠와 연결, 닫기 버튼은 활성·호버·포커스·변경 상태에서 표시.
- 스크롤은 사이드바·편집기·미리보기별로, 전체 창 스크롤 없음. 사이드바는 활동 아이콘·제목을 고정하고 패널 내용만 스크롤.
- 스크롤바: 기본 스크롤바를 숨기고 공통 `ScrollArea`의 오버레이 막대 사용(레이아웃 공간 없음, 스크롤 중·마우스 올림 시 표시, 막대 끌기·트랙 클릭). 적용: 사이드 패널·탭 줄·미리보기와 코드 블록·설정·문서 개요·팔레트·프로젝트 바꾸기 파일 목록. 우클릭 메뉴·대화상자 본문·업데이트 내역은 넘치는 경우가 드물어 휠 스크롤만 지원. 편집기는 Monaco 자체 막대.
- 입력란: 모든 텍스트 입력에 `autoComplete="off"`를 지정해 WebView2의 저장된 정보(자동 완성) 목록을 띄우지 않음.
- 창: 기본 1280×820, 최소 640×480(창 테두리 포함). 화면은 CSS 최소 폭 없이 창 안쪽 폭에 맞춰 줄어든다. 760px 이하에서 분할 보기는 상하 배치.
- 아이콘: 일반 UI·창 제어는 `@vscode/codicons` SVG 스프라이트(테마 글자색 상속), 파일·폴더는 `material-icon-theme` SVG(원본 색상), Monaco 위젯은 같은 버전의 Codicon 폰트 로컬 번들. 외부 요청 없음.

## 탐색기와 파일 관리

- 프로젝트를 열지 않았을 때만 폴더 열기 표시. 열린 뒤 문서가 없으면 문서 선택 안내·새 문서 진입.
- 루트 제목은 실제 폴더명(긴 이름 생략·전체 경로 툴팁), 우측에 기본/전체 보기 아이콘과 생성/새로고침 도구.
- 기본 보기: `.md`·`.mmd`·`.mermaid`·이미지(png·jpg·gif·webp·avif·bmp)와 하위에 그런 파일이 있는 폴더만. 전체 보기: 모든 항목, 빈 폴더는 안내·펼침 없는 행(관리·붙여넣기·드롭 가능). 보기 상태는 프로젝트별 복원. 확인할 수 없는 폴더는 숨기지 않는다.
- 생성·이름 변경·휴지통 이동, 잘라내기/복사/붙여넣기(탐색기 포커스의 Ctrl X/C/V·F2·Delete). 이름 충돌 시 새 이름 입력, 덮어쓰기 금지. 파일 클립보드는 앱 내부에서만 유지.
- 단일 파일 드래그로 같은 프로젝트 폴더에 이동. 닫힌 폴더 위 700ms 대기 시 자동 펼침. 폴더 자체 드래그·OS 외부 파일 가져오기 제외.
- 이동해도 열린 탭 경로와 미저장 버퍼 유지.
- 이미지 탭: png·jpg·gif·webp·avif·bmp(최대 10MB, SVG 제외)는 읽기 전용 이미지 탭으로 연다. 처음엔 창에 맞춤(큰 이미지만 축소). 휠은 커서 위치를 기준으로 확대·축소(5%~800%), 끌면 이동(가장자리 48px는 화면 안에 유지), 더블클릭·`맞춤`으로 다시 맞춤, `100%`·`−`/`+` 단계 버튼, 300% 이상은 픽셀을 선명하게 표시. 패널 크기가 바뀌면 맞춤 상태일 때만 다시 맞춤. 투명 부분은 체크무늬, 오른쪽 아래에 픽셀 크기·형식·파일 크기. 파일이 바뀌면 다시 불러오고, 없어지면 오류를 표시한다. 저장·다른 이름 저장·복구 대상이 아니고 세션에 탭으로 복원된다. 탐색기 기본 보기에도 보인다.
- 링크 갱신: 파일·폴더 이동(드래그·잘라내기 붙여넣기)과 이름 변경 전에 프로젝트의 `.md` 파일을 읽어 깨질 링크를 계산하고, 있으면 파일별 선택·변경 미리보기 창에서 `이동하고 링크 고치기`·`이동만`·`취소`를 고른다. 없으면 묻지 않고 이동. 대상은 인라인 링크·이미지·참조 정의이고, 다른 문서의 링크와 이동한 문서 자신의 상대 링크를 새 위치 기준으로 다시 계산한다(폴더 하위 경로 포함). 앵커·제목·`./`·꺾쇠·퍼센트 인코딩 표기는 원래 방식을 유지하고, 코드·HTML·외부 URL·문서 안 앵커는 건드리지 않는다. 저장하지 않았거나 외부 변경을 확인하지 않은 열린 문서는 제외하고 이유를 표시. 이동 실패 시 링크도 고치지 않고, 이동 뒤 일부 파일 갱신이 실패하면 실패 파일과 이유를 보여 준다. 대소문자만 바꾸는 이름 변경과 복사는 링크를 건드리지 않는다.

## 편집과 미리보기

- Monaco 찾기·바꾸기·들여쓰기, 찾기 창은 오버레이(본문 높이 유지). 문서 전환·보기 변경 간 실행 취소 이력 유지(최근 30개 모델).
- 미리보기: GFM 표·체크리스트·코드 블록(언어를 적은 블록은 편집기 테마 색으로 구문 강조, Monaco 내장 약 80개 언어·별칭·확장자로 인식, 모르는 언어나 10만 자 초과는 일반 텍스트), 문서 개요(오른쪽 위 플로팅 패널, Esc로 닫고 호출 버튼에 포커스 복원).
- 이미지: 로컬 이미지는 등록 경로 안에서 불러오고, 원격 이미지는 https만 표시(설정 `원격 이미지 표시`, 기본 켬)·http는 차단. `<img width/height>` 반영, 이미지는 줄 안에 놓여 배지가 나란히 서고 `align` 가운데 정렬이 된다. 표시할 수 없는 이미지는 대체 텍스트와 이유를 담은 작은 칩으로 표시.
- HTML: `<details>`·`<summary>`·`<kbd>`·`<sub>`·`<sup>`·`<mark>`·`<br>`·`<ins>`·`<del>`과 표·목록·정렬(`align`) 등 Markdown으로 만들 수 있는 태그를 표시하고 그 안의 Markdown도 렌더링. 스크립트·스타일·이벤트·폼·임베드는 차단, 허용 밖 태그는 글자만 표시. 보안 경계는 TECH_STACK 참고.
- front matter: 문서 맨 앞 `---`로 열고 `---`·`...`로 닫은 YAML 블록(최대 500줄, BOM 허용)은 미리보기 맨 위에 접힌 `속성` 표(최상위 `키: 값`, 중첩 줄은 값에 합침, 키가 없으면 원문)로 보이고, 개요·링크 검사·링크 갱신·블록 분할에서 빠진다. 편집기는 구분선을 흐리게, 키를 강조색으로 표시하고 Markdown 색을 쓰지 않는다. 닫히지 않았거나 맨 앞이 아니면 일반 Markdown(구분선).
- 큰 문서: 미리보기·개요·링크 검사는 빈 줄 단위 블록으로 나눠 바뀐 블록만 다시 파싱·렌더링. 100KB 이상 문서는 입력이 200ms 멈춘 뒤 미리보기·개요 갱신. 미리보기는 앞쪽 40블록을 먼저 그리고 나머지는 40블록씩 입력 사이에 채우며, 아직 그리지 않은 위치로 이동하면 그 위치까지 먼저 렌더링. 각주가 있는 문서는 나누지 않고, 빈 줄을 품은 HTML 컨테이너(`details`·`div`·`dl`·`table`·`blockquote`)는 닫는 태그까지 한 블록.
- 스크롤 동기화: 소스 줄 기반 양방향, 중간은 줄 보간, 상하단은 실제 끝 위치 연동. 하단 고정은 이미지·글꼴 높이 변경에도 유지하고 직접 스크롤·개요/링크 이동 시 해제.
- Mermaid: Markdown 코드 블록·독립 파일 미리보기, 편집 중 지연 렌더·결과 캐시(원문·테마·크기 기준 100개)·테마/글꼴 반영, 문법 오류 시 오류와 원문 표시. 독립 파일 편집은 일반 텍스트 모델.
- 이미지 붙여넣기: 편집기 Ctrl V 이미지 데이터를 프로젝트 `assets`에 고유 이름으로 저장하고 상대 경로 삽입(실행 취소 가능). 저장 중 문서가 바뀌면 삽입 취소·생성 경로 안내.
- 문서 링크: 경로·제목 앵커 자동 완성(한글·공백 검색, URI 인코딩 삽입), 깨진 로컬 링크·앵커 경고(본문 자동 수정 없음). 코드 영역·외부 URL·SVG 후보 제외. 입력 400ms 디바운스·5초 재검사.

## 문서 탭과 저장

- 탭: 넘치면 가로 스크롤(세로 휠로도 이동), 활성 탭 자동 노출, 끌어서 순서 변경(순서는 세션에 저장), 가운데 클릭으로 닫기, 같은 이름 문서는 구분되는 가장 짧은 폴더 경로 표시, 전체 경로 툴팁.
- 탭 우클릭: 닫기·다른 탭/오른쪽/모두 닫기·모두 저장·경로 복사·탐색기 위치 표시. Ctrl W 닫기, Ctrl Alt S 모두 저장, Ctrl Shift T 프로젝트별 최근 닫은 탭 재열기.
- 문서 닫기·프로젝트 탭 닫기·앱 종료·업데이트 설치 시 저장/저장 안 함/취소. 앱 종료는 모든 탭의 미저장 문서를 `프로젝트 · 문서` 목록으로 한 번에 묻는다. 저장 실패 시 버퍼·탭 유지.
- 저장 시 외부 변경을 확인하고 같은 폴더 임시 파일로 교체, UTF-8 BOM 유지. 다른 이름 저장은 등록 프로젝트 내부만.
- 외부 변경: 프로젝트 폴더 감시(변경 150ms 단위 묶음, `.git`·`node_modules`·`target`·`dist` 내부 제외)로 변경 시에만 검사, 앱 포커스 복귀 시 전체 재확인. 감시를 시작할 수 없으면 3초 주기 검사. 미편집 문서는 자동 갱신, 미저장 문서는 다시 읽기/내 편집 유지 선택. 삭제·읽기 실패 시 버퍼 유지.
- 미저장 복구: 변경 후 750ms 디바운스로 프로젝트별 임시본 저장. 시작 시 복구/버리기 선택 전 읽기 전용, 복구해도 원본 파일은 바꾸지 않는다. 손상 임시본은 명시적으로 버릴 때까지 보존.
- 재실행·프로젝트 전환 시 열린 문서·활성 탭·보기·개요·사이드바 복원, 사라진 문서는 제외하고 안내.

## 검색과 바꾸기

- 검색 조건: 입력란 안의 대소문자 구분·단어 단위·정규식 토글(`Alt C`·`Alt W`·`Alt R`)과 파일 조건(포함·제외할 파일). 파일 조건은 쉼표로 구분한 glob(`*`·`**`·`?`)이고, `/`가 없는 이름은 모든 위치에서, `/`가 있으면 프로젝트 루트 기준으로 맞추며 폴더가 맞으면 그 안 전체에 적용(대소문자 무시). 검색과 바꾸기는 같은 규칙(Rust `workspace/query.rs`)으로 문서 전체에 대해 맞추고 빈 문자열 일치는 건너뜀. 정규식은 Rust `regex` 문법(여러 줄 모드, 선형 시간), 잘못된 패턴은 이유 한 줄로 안내, 컴파일 크기 4MB 초과는 거부.
- 검색 사이드바: 검색어 지우기·결과 수·결과 새로고침, 파일별 접기·경로·줄 번호·일치 강조(여러 줄 일치는 첫 줄), 기본값과 다른 조건 요약 표시, 초기/진행/빈 결과/오류 구분, 폴더 범위 지정. 조건 변경 시 이전 결과 숨김. 검색어·조건·결과는 사이드바 보기를 바꿔도 유지(앱 실행 중).
- 프로젝트 바꾸기: 사이드바의 검색어·조건을 이어받아 열고 같은 조건으로 치환. 일반 모드는 대체어를 그대로 넣고, 정규식 모드는 `$1`·`${이름}`으로 그룹 참조(`$$`는 `$`). 조건을 바꾸면 이전 미리보기를 버림. 파일 선택 목록·읽기 전용 Monaco 차이 미리보기(나란히/통합, 좁은 폭은 통합)·선택 적용·파일별 결과. 미저장·외부 변경 미확인 문서 보호, 적용 전 전체 내용 검증·파일별 원자적 저장.
- 빠른 파일 열기: 파일명·경로 검색, 열 때마다 목록 갱신, 기존 탭 재사용.
- 검색·바꾸기·빠른 열기는 감시 중인 프로젝트의 파일 목록과 파일 내용을 캐시(내용 최대 64MB)하고 감시 이벤트로 바뀐 부분만 비움. 이미지·압축·글꼴 등 바이너리 확장자는 읽지 않고 생략 수에 포함. 결과는 경로순.

## 프로젝트

- 등록·이름/경로 검색·즐겨찾기·태그(태그별 그룹, 복수 태그는 각 그룹에 표시)·최근 사용순 정렬.
- 정렬·태그 필터는 앱 공통 드롭다운(`Dropdown`, WAI-ARIA 선택형 콤보박스, 설정의 언어·모드도 사용). 방향키·Home·End로 이동(비활성 항목 건너뜀), Enter·Space 선택, Esc 닫기, Tab·바깥 클릭·창 크기 변경 시 닫기, 글자 입력으로 항목 찾기. 포커스는 버튼에 남고, 목록은 아래 공간이 부족하면 위로 열리며 창 경계 안에 배치. 검색어·정렬·태그·즐겨찾기 필터는 사이드바 보기를 바꿔도 유지(앱 실행 중).
- OS에서 파일 열기(기본 프로그램·연결 프로그램·명령줄 인자): 파일을 포함한 등록 프로젝트 중 가장 안쪽 프로젝트의 탭으로 시작·전환해 파일을 열고 탐색기에 표시(현재 탭은 그대로 유지). 등록 프로젝트 밖의 파일이면 등록 없이 `External` 탭에 모아 연다: 다른 폴더의 파일을 열어도 기존 탭을 유지하고, 탐색기는 '열린 파일' 아래 폴더별 행(드라이브와 마지막 두 폴더만 남긴 짧은 경로, 전체 경로는 툴팁)과 OS로 연 파일만 표시한다. 미리보기 링크가 프로젝트 폴더 밖(`../`)이나 External 문서에서 다른 파일을 가리키면, 대상이 속한 등록 프로젝트 탭에서 열고 없으면 External에 추가해 열며, 대상이 없으면 '파일을 찾을 수 없습니다: 파일 이름' 토스트를 띄운다(프로젝트에서도 같은 문구). 편집·저장·외부 변경 감지·미저장 복구는 동작하고, 미리보기는 열린 파일의 폴더 아래 이미지만 표시. 새 문서·이름 변경·이동·휴지통·프로젝트 검색·바꾸기·빠른 열기·다른 이름 저장·이미지 붙여넣기는 쓸 수 없고, 폴더 행 메뉴의 '폴더를 프로젝트로 등록'으로 그 폴더의 문서를 새 프로젝트 탭으로 옮길 수 있다(External에는 다른 폴더 문서만 남음). External은 프로젝트 목록·세션·열린 탭 목록에 남지 않으며, 저장하지 않은 편집은 같은 파일을 다시 열면 복구를 묻는다. 앱이 이미 실행 중이면 새 창을 띄우지 않고 기존 창을 앞으로 가져와 거기서 연다(여러 파일은 차례로 처리).
- 항목: 32px 한 줄, 16px 아이콘·이름·열림 상태 점. 우클릭으로 열기·즐겨찾기·경로·표시 이름/태그·재연결·목록 제거(실제 파일 유지).

## 메뉴와 명령

- WebView 기본 우클릭 대신 앱 메뉴. 아이콘·구분선·단축키·체크·주의 작업 표시, 화면 높이에 맞춘 위치/스크롤. 방향키·Home/End 이동, IME 조합 중 보호, Esc/Tab·배경 클릭으로 닫고 호출 위치 포커스 복귀.
- 입력란·편집기 텍스트 메뉴(복사/잘라내기/붙여넣기/모두 선택)도 앱 메뉴. 클립보드 대기 중 내용이 바뀌면 수정 취소.
- 메뉴·팔레트·단축키는 공통 명령 실행기 사용. 실행 직전 대상 프로젝트·파일·문서 유효성 재검사, 우클릭 대상과 활성 문서 분리, 비동기 실패는 공통 오류 안내(상태 표시줄 위 오른쪽 아래 토스트, 6초 뒤 자동으로 닫히고 마우스를 올리거나 포커스가 있는 동안은 유지, 닫기 버튼).
- 명령 팔레트: 닫기 버튼·배경 클릭·Esc(한글 조합 중 보호), 입력창/닫기 버튼 Tab 순환.

## 설정

- 진입: 상태 표시줄 톱니바퀴·명령 팔레트·`Ctrl ,`. 별도 탭으로 열리며 기존 문서 탭과 이력 유지. 프로젝트와 독립된 전역 설정, 즉시 적용·자동 저장·기본값 초기화.
- 구성: 섹션은 일반(언어)·모양(모드·테마·인터페이스 글꼴 크기)·편집기(글꼴·글꼴 크기·자동 줄 바꿈)·미리보기(글꼴 크기)·정보(버전·업데이트·초기화). 왼쪽 섹션 목록은 스크롤해도 고정되고 현재 섹션을 강조하며, 누르면 그 섹션으로 이동해 제목에 포커스. 설정 패널 폭 640px 이하에서는 섹션 목록이 위쪽 가로 줄.
- 컨트롤: 언어·색상 모드는 공통 `Dropdown`, 기본값과 다른 항목은 컨트롤 왼쪽에 `기본값으로 되돌리기` 버튼(테마는 보고 있는 종류만 되돌림), 테마 카드는 한 줄에 여러 개 들어가는 작은 크기.
- 설정 검색: 항목 이름·설명·관련 단어(테마 이름 포함)로 거르고, 결과가 없는 섹션은 숨기고 목록에서 비활성. 결과가 없으면 안내, Esc로 검색어 지움.
- 언어: 시스템/한국어/English. 시스템 기본값은 한국어 계열 → 한국어, 그 외 → 영어(데스크톱 `sys-locale`, 브라우저 `navigator.language`). 사용자 문서 본문·파일·프로젝트 이름은 번역하지 않는다. Monaco는 공식 한국어 번들을 쓰고, 0.57에서 초기화 시 고정되는 찾기 위젯 문구만 어댑터로 바꾼다(Monaco 갱신 시 회귀 확인).
- 모드·테마: 시스템/라이트/다크, 모드별 테마 5종. 앱·Monaco·미리보기에 같은 테마 토큰 적용, 실행 중 시스템 변경 추종. 테마 카드는 `라이트 테마 | 다크 테마` 전환으로 한 종류씩 보이고, 처음엔 지금 적용 중인 종류(색상 모드를 바꾸면 그 종류)가 열리며 검색어가 한 종류의 테마 이름과 맞으면 그 종류로 바뀐다. 적용 중인 카드에 `적용 중` 표시.
- 글꼴 크기: UI 11~20px, 편집기 10~32px, 미리보기 12~32px. `[−] 숫자 px [+]` 입력(`NumberStepper`)으로 버튼·방향키는 1씩 범위 안에서 바꾸고, 직접 입력한 값은 범위 안일 때만 바로 적용, 범위 밖·빈 값은 빨간 테두리로 표시하고 포커스가 떠나면 원래 값으로. 기본값 UI·편집기 13px, 미리보기 15px, Light/Dark Modern.
- 편집기: 글꼴 이름을 쉼표로 구분해 입력. 데스크톱 앱에서는 설치된 글꼴 목록(고정폭 먼저, 각 이름을 그 글꼴로 표시, 한글 이름으로도 검색)을 보여 주고, 입력하면 커서가 있는 항목 기준으로 걸러 방향키·Enter·클릭으로 그 항목만 바꾼다. 목록은 설정을 열 때 한 번 읽어 앱 실행 중 재사용(약 1초). (Enter·선택·포커스 해제 시 적용, Esc 되돌림, 최대 200자, 문자·숫자·공백과 `, ' " . _ -`만 허용, 비우면 기본 글꼴). 입력 글꼴 뒤에 기본 글꼴(Cascadia Code·Consolas·맑은 고딕)을 대체로 붙이고 변경 차이 미리보기에도 적용. 자동 줄 바꿈 켜기/끄기(기본 켬). 열린 편집기 옵션만 바꿔 실행 취소 이력·스크롤 동기화 유지.
- 앱 정보: 실제 버전, 업데이트 확인·다운로드·설치.
