# 작업 공간 UI

관련 작업: W002~W037

## 구성

- 문서 탭과 창 제어를 하나의 최상단 행으로 통합, 별도 타이틀바 높이 제거
- 문서 탭·창 제어는 공통 배경 위의 34px 행, 콘텐츠 패널 외곽선은 그 아래에서 시작
- 사이드바 상단 아이콘 영역과 메인 탭 영역은 동일한 34px 기준으로 하단 경계선 정렬, 사이드바 외곽선 두께 반영
- 활성 탭은 콘텐츠와 연결된 모양, 우측 패널 모서리는 창 제어 아래에서 시작
- 탭 목록 상단 여백 없이 활성 탭·사이드바 외곽선의 상단 좌표 일치
- 문서 탭: 활성 탭만 얇은 외곽선·8px 상단 곡률, 비활성 탭은 테두리 없이 배치, 닫기는 활성·호버·키보드 포커스·변경 상태에 표시
- 탭 옆 빈 영역 및 사이드바 상단 아이콘 사이 빈 영역: 창 드래그, 앱 아이콘·제목·검색란 제외
- 사이드바 상단 가로 액티비티 영역: 탐색기·검색·프로젝트, 하단 밑줄로 선택 표시
- 사이드바: 실제 파일 트리·프로젝트 전체 내용 검색·프로젝트
- 프로젝트 항목: 32px 버튼 중심의 한 줄 목록, 16px 아이콘·프로젝트 이름·열림 상태 점 표시
- 본문: 문서 탭·경로·보기 전환·편집/미리보기
- 상태 표시줄: 왼쪽 끝 사이드바 열기/닫기·현재 프로젝트·커서 위치·문서 형식

## 시각 기준

- 어두운 앱 배경 위에 독립된 사이드바·콘텐츠 패널 배치, 패널별 1px 외곽선·8px 곡률·은은한 그림자
- 패널 사이 및 상단·좌우 6px 간격, 하단 4px 간격으로 콘텐츠 공간 유지
- 맞닿은 사이드바/콘텐츠의 이중 경계선 제거, 내부 구분선은 한쪽 면에만 적용
- 선택한 라이트·다크 테마의 중립 배경 및 구분선
- 선택 테마의 강조색과 선택 영역, 가는 선 아이콘
- 일반 UI·창 제어: `@vscode/codicons` SVG 스프라이트, 테마의 글자색 상속
- 파일·폴더: `material-icon-theme` SVG, README 전용·Markdown·열림/닫힘 폴더 아이콘 및 원본 색상
- 두 패널의 모서리 곡률 통일과 편집/미리보기의 배경 구분
- 전체 창 스크롤 대신 사이드바·편집기·미리보기별 스크롤
- 기본 창 1280×820, 최소 창 640×480, 760px 이하 분할 보기 상하 배치

## 상호작용

- 공통 컨텍스트 메뉴: 아이콘·구분선·단축키·체크 상태·주의 작업 표시, 실측 크기와 화면 높이에 따른 위치/스크롤 조정. 방향키·Home/End 이동, 비활성 항목 제외, IME 조합 중 보호, Esc/Tab·배경 클릭 닫기 및 호출 위치 포커스 복귀.
- WebView 기본 우클릭 메뉴 대신 Oxidoc 문맥 메뉴 사용. 탐색기 루트·빈 공간: 생성/경로/새로고침/모두 접기, 프로젝트 행: 열기/즐겨찾기/경로/표시 이름/태그/재연결/제거, 앱 빈 공간: 앱 명령. 입력란·편집기: 복사/잘라내기/붙여넣기/모두 선택, 비동기 클립보드 대기 중 내용·문서 변경 시 수정 취소. 팔레트 내 텍스트 메뉴의 Esc는 가장 위 메뉴부터 닫기.
- 파일의 탐색기 열기: 파일 선택 표시, 폴더/프로젝트: 해당 폴더 열기. 파일·폴더 절대/상대 경로 복사, 폴더 내 검색 범위 표시·전체 범위 복귀. 네이티브 경로는 등록 프로젝트 내부로 제한.
- 메뉴·팔레트·주요 앱 단축키: 공통 명령 실행기 사용. 실행 직전 busy·데스크톱·대상 프로젝트/파일/문서 유효성 재검사, 우클릭 대상과 활성 문서 분리, 비동기 실패의 공통 오류 전달. 생성·이름 변경·휴지통 확인 후에도 프로젝트 경계 유지.
- 프로젝트 목록: 등록·검색·정렬/태그 필터의 여백 축소, 즐겨찾기와 고유 프로젝트 수 한 줄 표시. 태그별 그룹·태그 없음 구분, 복수 태그 프로젝트는 각 그룹 표시

- 프로젝트 미열기 상태에서만 탐색기·빈 본문의 폴더 열기 표시. 프로젝트가 열리고 문서가 없으면 문서 선택 안내·새 문서 진입 제공
- 탐색기 루트 제목은 실제 프로젝트 폴더명, 긴 이름 생략 및 전체 경로 툴팁 표시
- 프로젝트 요약은 작은 아이콘·최소 여백, 생성/새로고침 도구는 루트 폴더명 행 우측에 통합

- 명령 팔레트: 우측 닫기 버튼·배경 클릭·포커스 위치와 무관한 Esc 닫기, 입력창/닫기 버튼 간 Tab 순환, 한글 조합 중 Esc 보호
- 스크롤 동기화: 중간 위치는 소스 줄 보간, 상단·하단은 실제 스크롤 끝 위치 연동. 하단 도달 후 이미지·글꼴 높이 변경에도 유지, 직접 스크롤·개요/링크 이동 시 고정 해제
- 문서 개요: 본문 오른쪽 위 반투명·배경 블러 플로팅 패널, 편집기·미리보기 폭 유지·자체 스크롤·닫기 버튼/Esc·닫은 뒤 호출 버튼 포커스 복원
- Monaco 찾기/바꾸기 아이콘: 동일 버전 전용 Codicon 폰트 로컬 번들, 앱 SVG 아이콘과 분리
- Monaco 찾기/바꾸기 창은 오버레이 표시, 상단 추가 공간 생성 비활성화로 편집 본문/스크롤 높이 유지

- 문서 선택·탭 전환·닫기·다시 열기, 파일·폴더 생성·이름 변경·휴지통 이동
- 문서 탭 우클릭: 닫기·다른 탭·오른쪽·모두 닫기, 모두 저장·경로 복사·탐색기 위치 표시. 일괄 저장 확인·중간 저장 실패 시 탭 보존. Ctrl W 현재 탭 닫기·Ctrl Alt S 모두 저장·Ctrl Shift T 프로젝트별 최근 닫은 탭 재열기.
- 외부 변경: 3초 메타데이터 폴링·포커스 복귀 검사, 로드된 폴더 트리 갱신. 열린 문서는 다시 읽기/내 편집 유지 안내, 미저장 내용 자동 덮어쓰기 금지. 삭제·읽기 실패 시 버퍼 유지 및 다른 이름 저장.
- 미저장 복구: AppData의 프로젝트별 임시본, 변경 후 750ms 디바운스·원자적 저장. 시작 시 복구/버리기 선택 전 편집 읽기 전용, 복구 시 원본 파일 미변경·외부 변경 충돌 안내. 저장·폐기·정상 종료 시 정리, 손상 임시본은 명시적 폐기 전 보존. 프로젝트당 본문+저장 기준 합계 20MB·최대100문서.
- 탐색기 파일·폴더 잘라내기/복사/붙여넣기, 탐색기 포커스의 Ctrl X/C/V·F2·Delete. 잘라내기 흐리게 표시·이동 성공 후 클립보드 해제, 이름 충돌 시 새 이름 입력·덮어쓰기 금지. 폴더 이동 시 열린 하위 문서 경로·미저장 버퍼 유지. 파일 클립보드는 앱 내부에서만 유지하며 편집기/입력란의 텍스트 단축키와 분리.
- 탐색기 단일 파일 드래그 → 같은 프로젝트의 폴더 행/최상위 폴더명 드롭으로 이동, 대상 강조·완료 후 폴더 펼침. 닫힌 대상 폴더 위 700ms 대기 시 자동 펼침·자식 로드, 이탈·드롭·드래그 종료 시 예약 취소. 이름 충돌 시 이동 취소, 열린 탭 경로·미저장 버퍼 유지. 폴더 자체 이동·OS 외부 파일 가져오기 제외.
- 실행 중 문서별 편집 내용 유지 및 변경 표시
- Markdown 편집·분할 보기·미리보기 전환
- 전체 텍스트 검색·줄/열 이동, 프로젝트 이름·경로 검색 및 즐겨찾기·태그·최근 정렬
- 검색 사이드바: 제목과 전체 바꾸기 아이콘 분리, 검색어 지우기·대소문자 옵션·결과 수 정렬. 파일별 접기/펼치기·경로·줄 번호·일치 강조, 초기/진행/빈 결과/오류 구분. 조건 변경 시 이전 결과 숨김, 폴더 범위·키보드 이동·테마 및 UI 글꼴 설정 반영.
- Ctrl K 프로젝트 검색, Ctrl B 사이드바 전환, Ctrl P 파일 빠른 열기, Ctrl Shift P 명령 팔레트, Ctrl Shift S 다른 이름으로 저장, Ctrl F/H 문서 찾기·바꾸기, Ctrl Shift H 프로젝트 전체 바꾸기
- 빠른 파일 열기: 파일명·경로 검색, 화살표/Enter 선택·Esc 닫기, 기존 탭 재사용·실패 안내. 열 때마다 파일 목록 갱신, 의존성/출력 폴더 제외·20,000항목/깊이64 제한 및 부분 결과 안내.
- 프로젝트 바꾸기: 파일별 변경 전후 미리보기·체크박스 선택 적용·개별 결과 안내. 미저장/외부 변경 미확인 문서 보호, 전체 사전 내용 검증 및 파일별 원자적 저장. 리터럴 문자열 치환, 파일5MB·프로젝트20MB/100파일 제한·메모리 할당 전 크기 검사.
- 프로젝트 바꾸기 화면: 검색/대체 입력 도구막대, 전체·부분 선택 및 선택 파일/변경 건수, 독립 스크롤 파일 목록·읽기 전용 Monaco 차이 미리보기. 나란히/통합 보기·줄 번호·변경 강조·변경 없는 영역 접기, 좁은 폭에서 통합 보기. 초기/결과 없음/진행/오류/파일별 적용 결과 분리, 적용 후 남은 파일 미리보기 유지. UI·편집 글꼴 설정과 테마 반영, Tab/Esc·결과 펼치기·닫기 포커스 복원.
- 이미지 붙여넣기: 편집기 Ctrl V의 이미지 데이터를 프로젝트 assets에 고유 이름 저장·현재 문서 상대 경로 삽입·실행 취소 지원. PNG/JPEG/GIF/WebP 시그니처·10MB 검증. 텍스트/찾기 입력의 붙여넣기와 분리, 저장 중 문서가 바뀌면 생성 이미지 경로 안내·삽입 취소.
- 문서 링크: Markdown 링크/이미지 경로·제목 앵커 자동 완성, 한글·공백 표시 이름 검색 및 URI 인코딩 삽입. 코드 영역 제외·SVG 이미지 후보 제외. 깨진 로컬 파일 및 현재 문서 제목 앵커 경고, 참조형 링크 지원·외부 URL 검사 제외. 입력400ms 디바운스·5초 재검사·트리 변경 갱신·최대500링크, 경고로만 표시·본문 자동 수정 제외.
- 선택된 액티비티 재클릭 시 현재 패널 유지, 사이드바 숨김 후 상태 표시줄 왼쪽 버튼 또는 Ctrl B로 복원
- 타이틀바 빈 영역 드래그·더블클릭, 최소화·최대화·복원·닫기
- 브라우저 미리보기의 네이티브 창 제어 비활성화

## 구현 경계

- 데스크톱은 실제 프로젝트 등록·폴더 탐색·문서 읽기/저장·등록 목록 영속화 지원, 브라우저만 샘플 데이터 사용
- 문서 닫기·프로젝트 전환·앱 종료 시 미저장 변경 확인, 저장 실패 시 버퍼 유지
- 프로젝트별 문서 경로·활성 탭·레이아웃 영속화, 사라진 문서 복원 제외 및 안내. 문서 전환·보기 변경 간 Monaco 실행 취소 이력 유지(최근 30개 모델)
- 미리보기 원시 HTML·원격 이미지 차단, 상대 문서·로컬 래스터 이미지 지원, HTTP/HTTPS 기본 브라우저 열기. 제목 개요·위치 이동 및 소스 줄 기반 양방향 스크롤 동기화
- 프로젝트·문서·저장·레이아웃 상태는 Zustand, 커서와 대화상자는 React에서 관리, Monaco와 렌더러는 지연 로딩
- 타이틀바 제어 권한은 해당 Tauri 창 명령으로 제한

## 검증

- 자동 검사: 타입·린트·UI/상태 테스트·프런트엔드 빌드·포맷·Rust Clippy 및 실제 파일 테스트
- 브라우저 확인: 1440×900 및 640×480 레이아웃, 문서 전환·검색 단축키
- 네이티브: 변경 설정으로 앱 재실행, 실제 창 드래그·제어 동작은 사용자 확인 필요
- 빌드 안내: 지연 로딩된 Monaco 청크의 크기 경고 존재
